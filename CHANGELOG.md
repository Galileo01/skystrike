# Changelog

All notable changes to SkyStrike will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-24

### Added

- 60 FPS terminal shooter with double-buffered ASCII rendering and parallax stars.
- Cross-terminal input modes with tap/hold movement, single fire, and toggled auto-fire.
- Pause/menu flow, four difficulty presets, and per-difficulty persistent high scores.
- Small and heavy enemies with differentiated scores, combo bonuses, and score popups.
- Scatter, Repair, and EMP pickups with notices and timed-effect HUD indicators.
- Difficulty-aware enemy density and top-entry X targeting.
- Optional debug HUD and preassigned enemy reward labels via `--debug`.

### Supported platforms

- macOS
- Linux
